# Эмулятор командной оболочки

Практическая работа по дисциплине «Конфигурационное управление».

**Вариант №19.**

## Общее описание

Проект представляет собой эмулятор UNIX-подобной командной оболочки
с графическим интерфейсом (Tkinter). Поддерживает параметры командной
строки и выполнение стартовых скриптов.

Выполненные этапы:

- Этап 1. REPL.
- Этап 2. Конфигурация.

## Этап 1. REPL

На первом этапе реализован минимальный прототип эмулятора
с графическим интерфейсом.

Добавлены:

- GUI-окно на Tkinter;
- заголовок окна формируется из реальных данных ОС:
  `Эмулятор - [username@hostname]`;
- разбор команды и аргументов по пробелам;
- команды-заглушки `ls` и `cd`;
- команда `exit`;
- обработка неизвестных команд;
- обработка ошибок при выполнении команд.

Эмулятор работает в цикле до выполнения команды `exit`.

## Этап 2. Конфигурация

Добавлена возможность настройки эмулятора через параметры
командной строки.

Поддерживаются параметры:

- `--vfs` — путь к физическому расположению VFS;
- `--script` — путь к стартовому скрипту.

При запуске программа выводит отладочную информацию о переданных
параметрах.

Проверяется только существование файла стартового скрипта.
Существование пути к VFS на данном этапе не проверяется.

Если указан стартовый скрипт, команды из него выполняются
последовательно:

- команда отображается на экране перед выполнением;
- отображается результат выполнения команды;
- пустые строки пропускаются;
- строки, начинающиеся с `#`, считаются комментариями;
- при ошибке команды выводится сообщение, и выполнение скрипта
  продолжается со следующей строки;
- команда `exit` завершает работу эмулятора.

Если стартовый скрипт не указан — эмулятор открывает
графический интерфейс в интерактивном режиме.

Если указан `--script`, эмулятор работает в headless-режиме
(без графического окна) — это позволяет запускать его
из shell-скриптов.

## Структура проекта

- `src/` — исходный код эмулятора;
- `src/main.py` — основной файл (GUI + headless, параметры командной строки);
- `src/parser.py` — разбор пользовательского ввода;
- `src/commands.py` — команды и класс `CommandResult`;
- `tests/` — тесты и стартовые скрипты;
- `tests/start_ok.txt` — успешный стартовый сценарий;
- `tests/start_error.txt` — сценарий с ошибочной командой;
- `tests/test_default.sh` — тест запуска со стартовым скриптом;
- `tests/test_parameters.sh` — тест параметров командной строки;
- `tests/test_invalid_script.sh` — тест отсутствующего скрипта;
- `tests/test_skip_errors.sh` — тест пропуска ошибок в скрипте;
- `run.sh` — скрипт запуска;
- `README.md` — документация проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Запуск

Обычный запуск (открывается графический интерфейс):

```bash
./run.sh
```

Или напрямую:

```bash
python3 -m src.main
```

## Параметры командной строки

Передача пути к VFS:

```bash
./run.sh --vfs my_vfs
```

Передача стартового скрипта:

```bash
./run.sh --script tests/start_ok.txt
```

Одновременная передача двух параметров:

```bash
./run.sh --vfs my_vfs --script tests/start_ok.txt
```

## Примеры интерактивного режима

```text
$ ls /tmp
ls: args=['/tmp']

$ cd /tmp
cd: args=['/tmp']

$ ls
ls: args=[]

$ unknown
unknown: command not found

$ exit
Bye.
```

## Пример стартового скрипта

Файл `tests/start_ok.txt`:

```text
# Stage 2 success
ls /tmp
cd /tmp
ls
exit
```

Запуск:

```bash
./run.sh --script tests/start_ok.txt
```

Пример результата:

```text
VFS: (не указан)
Скрипт: tests/start_ok.txt
$ ls /tmp
ls: args=['/tmp']
$ cd /tmp
cd: args=['/tmp']
$ ls
ls: args=[]
$ exit
```

## Обработка ошибок в стартовом скрипте

Ошибочные строки не прерывают выполнение скрипта.
При ошибке команды выводится сообщение, и эмулятор продолжает
выполнять следующие строки.

Файл `tests/start_error.txt`:

```text
# Stage 2 error-skip test
ls /tmp
unknown_command
cd /tmp
ls
exit
```

Пример результата:

```text
VFS: (не указан)
Скрипт: tests/start_error.txt
$ ls /tmp
ls: args=['/tmp']
$ unknown_command
unknown_command: command not found
$ cd /tmp
cd: args=['/tmp']
$ ls
ls: args=[]
$ exit
```

## Тестирование

Shell-тесты:

```bash
./tests/test_default.sh
./tests/test_parameters.sh
./tests/test_invalid_script.sh
./tests/test_skip_errors.sh
```

При успешном прохождении каждый тест выводит:

```text
TEST PASSED
```
